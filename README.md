# H4X ALTAF | Premium Hosting Platform 🔥

H4X ALTAF ek advanced aur premium hosting platform hai jahan aap apne Python bots, HTML websites, aur scripts 24/7 host kar sakte hain. Isme ek shandar dark theme, fire animations, aur music player ka system hai.

## 🚀 Features
- **User Authentication:** Secure Login & Signup system.
- **Bot Hosting:** Apni `bot.py` ya `.zip` file upload karke host karein.
- **Admin Panel:** Admin users ko coins de sakta hai aur redeem codes bana sakta hai.
- **Redeem System:** Users admin se code lekar apne coins add kar sakte hain.
- **Live Console:** Terminal jaisa console jahan error logs dikhte hain.
- **4 Color Themes:** Red, Blue, Green, Purple themes.
- **Fire & Music:** Background me real fire animation aur Phonk music player.

## 📁 File Structure
- `index.html` / `login.html` / `signup.html` - Authentication pages
- `dashboard.html` - Main user dashboard
- `upload.html` / `my-hosting.html` - File upload aur hosting management
- `admin.html` - Admin control center
- `pricing.html` / `coins.html` - Coin buying aur redeeming
- `style.css` - Master stylesheet (sabhi pages ke liye)
- `script.js` - Master javascript (fire, music, theme)
- `app.py` - Backend server (Flask API)
- `requirements.txt` - Python dependencies
- `runtime.txt` - Python version for hosting

## 🛠️ How to Run Locally (Mobile/PC)
1. Saari files ko ek folder me rakhein.
2. `index.html` ko kisi bhi browser (Chrome/Brave) me open karein.
3. Register karke login karein aur dashboard ka maza lein.

## 🌐 Backend Setup (Optional)
Agar aap real hosting chalana chahte hain toh:
1. Python install karein.
2. Terminal me run karein: `pip install -r requirements.txt`
3. Phir server start karein: `python app.py`

## ⚠️ Note
Yeh project abhi demo mode me hai. Real file hosting aur database ke liye aapko VPS ya cloud server (Render/Railway) ki zarurat padegi.
