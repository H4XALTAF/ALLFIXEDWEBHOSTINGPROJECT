FREQUENTLY ASKED

Yaha par aapke saare sawalo ke jawab milenge.

Mera bot kaise kaam karta hai? +
Aapko sirf apna bot.py file upload karna hai. Hamara server usko automatically run kar dega. Aap "My Hosting" page par jakar usko Start/Stop kar sakte hain.
Coins kaha se milte hain? +
Aap Pricing page se coins khareed sakte hain. Ya fir Admin aapko Redeem Code de sakta hai, jise aap "My Coins" page par redeem kar sakte hain.
Bot band (offline) ho gaya toh kya karein? +
Agar aapka bot offline ho jata hai, toh uske error logs check karein. Agar code me error hai, toh usko thik karke dobara upload karein. Agar server down hai, toh hum jaldi hi usko fix kar denge.
Kya main HTML website host kar sakta hu? +
Haan bilkul! Aap apni sari HTML, CSS, JS files ek .zip file me daal kar upload karein. Hamara server use automatically extract karke host kar dega.
